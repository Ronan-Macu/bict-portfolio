\# IT Asset Manager



\## Project Overview



A basic IT asset management system

for a fictional small organisation.



\## Organisation



\- Employees: 15

\- Laptops: 12

\- Desktop computers: 3

\- Network: Shared office network



\## Project Objectives



\- Record company devices.

\- Track operating systems.

\- Monitor software update status.

\- Identify basic security risks.

\- Recommend security improvements.



\## Device Information



Each device record will contain:



\- Unique asset ID

\- Device type

\- Operating system

\- Assigned employee

\- Last update date

\- Security status



\## Initial Features



\- Add a device.

\- View all registered devices.

\- Search for a device by asset ID.

\- Update a device's information.

\- Identify devices needing security attention.



\## Security Status Rules



Security status will be manually assigned.



\- Secure: No known outstanding security issues.

\- Needs attention: A known issue requires investigation or action.

\- Unknown: The device has not yet been assessed.



The system will not automatically verify whether a device is secure.



\## Planned Technologies



\- Python

\- SQLite

\- Git and GitHub
